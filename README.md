# funnel-builder-dist

The built Tampermonkey script from the private `funnel-builder` repo. Do not edit here: change the source repo and run `python3 build.py --publish`.

Install: open [funnelish-fill.user.js](https://raw.githubusercontent.com/vincentmertens-nivento/funnel-builder-dist/main/funnelish-fill.user.js) with Tampermonkey installed.
